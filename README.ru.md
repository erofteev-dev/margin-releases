## Установка

1. Откройте [последний релиз](https://github.com/erofteev-dev/margin-releases/releases/latest).
2. Скачайте `margin-<версия>.apk` из раздела **Assets**.
3. Откройте файл на телефоне. При необходимости разрешите браузеру или файловому менеджеру устанавливать приложения.
4. В Margin откройте **Настройки** и подключите Claude и/или Codex через системный браузер.
   Для Claude перенесите код авторизации из браузера обратно в приложение.
5. Удерживайте пустое место рабочего стола → **Виджеты** → **Margin**.

Для обновления установите новый APK поверх текущей версии. Удалять приложение не нужно:
удаление стирает локальные настройки и сохранённые входы.

## Аккаунты хранятся на устройстве

Margin подключается к сервисам напрямую с устройства, без сервера-посредника Margin.
Токены входа хранятся локально в зашифрованном виде с использованием Android Keystore.

Margin — независимое приложение, не официальный продукт Anthropic или OpenAI.
Совместимость зависит от OAuth и API провайдеров и может измениться.

## Фоновое обновление

Фоновое обновление запрашивается раз в 15 минут. Android, Doze и ограничения батареи могут его задержать.
Таймер пересчитывается при перерисовке виджета и не обновляется каждую секунду.
Для немедленной попытки обновления нажмите на виджет.

На MIUI может потребоваться включить автозапуск и разрешить фоновую работу.
После принудительной остановки приложения откройте Margin снова.

## Проверка загрузки

В каждом релизе есть файл `SHA256SUMS-<версия>` с контрольной суммой SHA-256 APK.
Обновления подписываются одним ключом Margin. Отпечаток сертификата подписи SHA-256:

```text
56fa90f85f6faef9e150ad2ddb5617b23f2a944b781b133b994add08b6aae7c3
```

Этот репозиторий содержит описание, скриншоты и установочные файлы в разделе Releases.
Исходный код здесь не публикуется.
